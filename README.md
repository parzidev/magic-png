# magic-png

Magic PNG oluşturmak için geliştirilmiş WPF/C# uygulaması.

Kaynak kodu `sihir/MagicPng/` altında bulunur. Eski `magicpngexe` dağıtım repository'sinin commit geçmişi bu repository ile birleştirilmiştir; aynı derlenmiş dosyaların ikinci bir `app/` kopyası güncel ağaçta tutulmaz.

Yeni build çıktıları için GitHub Releases kullanılması, `bin/` ve `obj/` klasörlerinin kaynak ağacına eklenmemesi önerilir.
